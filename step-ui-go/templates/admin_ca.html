Инструкция: создание JWK-провизионера на внешнем Step-CA

Step-CA UI взаимодействует со Step-CA через JWK-провизионер и выпускает сертификаты со сроком действия до 10 лет (87600h). На сервере внешнего CA выполните:

1. Создание нового JWK-провизионера с паролем и нужными лимитами: 
step ca provisioner add admin \
  --type JWK \
  --create \
  --x509-default-dur 8760h \
  --x509-max-dur 87600h
CLI запросит пароль для шифрования ключа provisioner. Если конфиг не в дефолтном каталоге, укажите --ca-config /etc/step-ca/config/ca.json.
2. Если провизионер уже существует, обновите его claims: 
step ca provisioner update admin \
  --x509-default-dur 8760h \
  --x509-max-dur 87600h \
  --ca-config /etc/step-ca/config/ca.json
3. Перезапустите службу step-ca: 
sudo systemctl restart step-ca

После этого введите имя провизионера и заданный пароль в форме выше, загрузите сертификаты Root и Intermediate CA и нажмите «Сохранить настройки».
